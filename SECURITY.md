# Security Policy

## Supported Versions

Currently, only the `main` branch (and latest alpha/beta releases) are actively supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project (e.g. credential leakage in logs, unsecured API calls), please **DO NOT** open a public issue.

Instead, please send a direct message to the repository owner or use GitHub's private vulnerability reporting feature (if enabled on this repository). 

We will prioritize resolving security issues promptly.
